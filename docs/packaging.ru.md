# Сборка пакетов

[English](packaging.md)

## Поиск во время работы

Шелл ищет `polkit-agent-helper-1` и `gvfsd-mtp` в `PATH`, затем проверяет пути дистрибутивов. Для polkit предусмотрен `/run/wrappers/bin/polkit-agent-helper-1` в NixOS; используйте системную привилегированную обёртку, а не непривилегированную копию помощника.

Шелл и `tools/theme.py` ищут `sddm/themes/yami` в абсолютных каталогах из `XDG_DATA_DIRS` по порядку, затем проверяют `/usr/share/sddm/themes/yami`. Если переменная не задана или пуста, используется `/usr/local/share:/usr/share`. Выбирается первая существующая тема. Смена палитры и обоев по-прежнему требует права записи; поиск не делает тему в Nix store доступной для записи. Для генерации при сборке остаётся `theme.py --sddm DIR`.

## Обновления через пакетный менеджер

Соберите шелл с дополнительной Cargo-фичей `package-managed`:

```sh
cargo build --release --locked --workspace --features package-managed --manifest-path shell/Cargo.toml
```

Она отключает проверки по расписанию, заменяет вкладку обновлений сообщением о пакетном менеджере, а `yami update` завершает с кодом 1 и объяснением. Точки входа обновления, смены версии и отката отказываются работать до обращения к клону исходников или установленным бинарникам. Обновляйте и откатывайте пакетным менеджером. Сборки без этой фичи сохраняют обычное обновление.

## Поддержка Nix

Эти изменения переносимости — первый шаг к декларативной поддержке Nix. Flake, пакет, модуль Home Manager и модуль NixOS пока не включены. Не запускайте `install.sh` для установки, которой управляет пакетный менеджер.
